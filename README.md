## Domain
Sports Analytics (Football/Soccer)

## Dataset
- **Source:** Kaggle (2022-2023 Season)
- **Description:** Comprehensive player statistics across the top 5 European leagues. Includes standard metrics (goals, assists, minutes) and advanced underlying analytics (Shot-Creating Actions, progressive passes, pressures).
- **Format:** Semicolon-delimited CSV, latin-1 encoding.

## Setup Instructions
1. Clone this repository to your local machine.
2. Ensure you have Python 3.8+ installed.
3. Install dependencies using: `pip install -r requirements.txt`

## Running the Dashboard
The interactive Streamlit dashboard visualizes the findings from our CRISP-DM pipeline.
Run the following command in your terminal:
```bash
streamlit run dashboard.py
```
Open the provided Local URL (typically `http://localhost:8501`) in your web browser.
